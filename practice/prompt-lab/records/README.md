# 실행 후 기록

실제 모델 출력은 아직 넣지 않았다. `template.json`의 null은 미실행 상태이며 성공·실패를 뜻하지 않는다.

개인 작업 사본에서 조건마다 template을 복사한다. 두 번의 원문은 run-1.txt·run-2.txt에 저장하고 `pnpm compare` 결과를 네 열에 옮긴다. 출력 앞뒤 공백은 비교에서 제거한다. 길이는 Unicode code point 수이며 토큰 수가 아니다. 금지 항목 열은 ⑤의 금지 단어 목록을 기준으로 센다. 다른 실험에는 적용 여부도 메모한다.

모델·반환 버전·실행 시각·프롬프트 SHA256·파라미터·생략된 항목을 함께 적는다. 설정을 노출하지 않는 UI는 값을 추측하지 않고 `미노출`로 기록한다. 각 실행은 새 대화에서 같은 조건으로 한다.

출력은 검토 후 공유한다. 토큰·키·개인 경로·이메일·계정 식별자·실제 업무 자료를 기록하지 않는다. raw HTTP 응답·헤더·전체 대화 기록은 올리지 않는다.
