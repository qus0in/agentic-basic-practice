# 교안 실습 검증

교안: [교안 실습 검증](https://abc.noco.kr/cases/practice-check), **검증 스크립트 만들기 / 실행 환경 맞추기 / 통과 후 남는 문제**.

[start](start/README.md)에서 기존 검증을 읽고 경계값 테스트를 추가한다. [done](done/README.md)은 비교용 완성 예제다. 두 폴더 모두 독립적으로 `pnpm install --frozen-lockfile`, `pnpm test`, `pnpm verify`를 실행할 수 있다. 명령의 작업 위치와 Docker 실행은 각 README를 따른다.
